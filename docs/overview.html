Der Pivot in einem Satz: Der Code-Worker wechselt vom einmaligen CORTEX.COMPLETE (rät, degradiert über Iterationen) zum agentischen Worker (Cortex Code Agent SDK) — der äußere deterministische Loop und das frozen-test Gate bleiben unverändert das Herz. 1.7 (Checkpointing) wurde verworfen (Recovery ist task-granular über die append-only Spur).
Quelle: docs/COMPONENT_AUDIT.md, spec/Phase1_Orchestrator_Loop.md, docs/superpowers/specs/2026-06-28-agentic-worker-migration-design.md

Der deterministische Loop (das Herzstück)

load_taskLOCKED aus TASK_SPECS + PROJECTS-Lookup; Job läuft als ORCH_PROJ_<ID>
→
DEVELOPER-Node 🟠agentischer Worker (Cortex Code SDK): schreibt/führt aus/iteriert im cwd (= gemountetes CODE_STAGE), liefert schema-validiertes Artefakt · war: One-Shot COMPLETE
→
run_testsfrozen Tests über den Artefakt-Baum, pytest, Exit-Code+Log → TEST_RESULTS
→
gateliest nur den Exit-Code — kein LLM-Urteil
PASS → RUNS=DONE → nächster Task
FAIL → TEST_RESULTS-Feedback → DEVELOPER-Node (Loop, ≤ MAX_ITER)
≥ MAX_ITER → STOP + Report, RUNS=NEEDS_HUMAN (kein Endlos-Loop)

Kernprinzip: Determinismus statt Selbstdisziplin — der Agent ist nicht-deterministisch, aber die eingefrorenen Tests sind die einzige „done"-Autorität. Held-out-Tests (für den Agenten unsichtbar) verhindern Overfitting.

Tragende Entscheidungen

Determinismus-Gate
Nur grüner Exit-Code = PASS. Nie „der Agent sagt fertig".
Cortex intern, kein EAI
OAuth-Token aus /snowflake/session/token; Egress zum eigenen Account bewiesen.
Feedback-Loop = Tabellen, nicht GitHub
Läuft überall; GitHub ist nur Liefer-Artefakt (Phase 3), nie der Loop.
Tenant = Datenbank
Isolierte DBs statt RAP (operativ zu teuer). Mehrere Instanzen via .env.
Append-only + RBAC
Jede Änderung = neue Zeile; LEAD nur INSERT; keine autonomen DROPs (Versionierung + human-gated Cleanup).
Agentischer Worker
Cortex Code SDK statt One-Shot; Gate bleibt die Autorität.
LangGraph MIT only
Nur die Library; nie langgraph-api/cli (Elastic 2.0).
Governance
Agents build+test; Humans own the blast radius (Account/Security/Network/DROP = HITL).
